02 How I build

An AI agent writes. I review every line.

My Claude Code workflow, shown on Jups Fintrack: a full-stack finance app that went from first commit to daily use in 4 days.

Step 1

Start from memory.

Each project has a CLAUDE.md and a vault note of decisions and gotchas, so the agent resumes with full context.

Step 2

Build with the agent, review each change.

Typecheck after every edit, 16 commits in all, and nothing merges that I haven't read.

Step 3

Test in a real browser before it ships.

The agent drives the browser through MCP at phone and desktop widths, and test runs must leave the data unchanged.
